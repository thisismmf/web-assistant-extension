# Web Assistant Extension

کنسول تمرین «دستیار وب» که شامل رابط وب واکنش‌گرا و بستهٔ افزونهٔ مرورگر (Chrome/Edge/Firefox) است. تمام نیازمندی‌های اجباری و اختیاری تمرین پیاده‌سازی شده‌اند:

- نوار جستجو که عبارت را مستقیماً در Google در زبانه‌ای جدید باز می‌کند.
- کارت‌های «دسترسی سریع» به همراه افزودن، ویرایش و حذف با آیکن دلخواه (اموجی یا متن کوتاه)، ذخیره شده در LocalStorage.
- تقویم ماهانه میلادی و شمسی با قابلیت جابه‌جایی بین ماه‌ها، بازگشت سریع به امروز، مشخص‌کردن روز انتخابی و روزهای دارای یادداشت.
- بخش «یادداشت‌های عمومی» (بدون تاریخ) با افزودن/ویرایش/حذف.
- بخش «یادداشت روز» که با کلیک روی تقویم به تاریخ مربوطه متصل می‌شود؛ وضعیت یادداشت‌های هر روز با نقطه‌ی رنگی در تقویم دیده می‌شود.
- داده‌ها در LocalStorage نگه‌داری می‌شوند و بین بارگذاری‌ها باقی می‌مانند.
- نسخهٔ کامل افزونه مبتنی بر Manifest V3 با آیکن‌های چند اندازه.

## ساختار مخزن

```
web/                      // نسخهٔ وب (index.html فقط فایل shared را بارگذاری می‌کند)
extension/
  manifest.json           // پیکربندی افزونه
  popup.html              // رابط افزونه (همان رابط صفحهٔ وب)
  shared/
    styles.css            // استایل‌های مشترک
    app.js                // تمام منطق به صورت Vanilla JS بدون ماژول/فریم ورک
  icons/                  // آیکن‌های PNG چند اندازه
```

> کد رابط در یک فایل واحد `extension/shared/app.js` نگه‌داری می‌شود و هیچ فریم‌ورک/کتابخانه‌ای استفاده نشده است.

## اجرای نسخهٔ وب

1. از مسیر مخزن باز کنید: `web/index.html`
   - می‌توانید فایل را مستقیم در مرورگر باز کنید (`Cmd/Ctrl + O`) یا از یک وب‌سرور ساده استفاده کنید.
2. برای سرو محلی:
   ```bash
   cd /path/to/web-assistant-extension/web
   python3 -m http.server 5173
   # سپس به آدرس http://localhost:5173 مراجعه کنید
   ```
3. تمام امکانات (جستجو، میانبرها، تقویم، یادداشت‌ها) بدون وابستگی به سرور عمل می‌کنند و داده‌ها در LocalStorage همان مرورگر ذخیره می‌شوند.

## نصب افزونه

### Chrome / Edge

1. مرورگر را باز کنید و به صفحه‌ی `chrome://extensions` (یا `edge://extensions`) بروید.
2. گزینه‌ی **Developer mode** را فعال کنید.
3. روی **Load unpacked** بزنید و پوشه‌ی `extension` را انتخاب کنید.
4. آیکن «WA» را پین کنید؛ پنل بازشو همان رابط کامل وب است.

### Firefox

1. به `about:debugging#/runtime/this-firefox` بروید.
2. روی **Load Temporary Add-on...** کلیک کرده و فایل `extension/manifest.json` را انتخاب کنید.
3. افزونه با همان امکانات اجرا می‌شود. (فیلد `browser_specific_settings` در `manifest.json` برای سازگاری با Gecko اضافه شده است.)

## نکات پیاده‌سازی

- **تقویم دوحالته**: `CalendarController` در `extension/shared/modules/calendar.js` منطق تولید ماتریس روزها و مشخصه‌های امروز/انتخابی/دارای یادداشت را مدیریت می‌کند. برای حالت شمسی، توابع تبدیل `toJalali` و `fromJalali` در `modules/jalali.js` استفاده شده‌اند و جابه‌جایی بین ماه‌های جلالی/میلادی بدون خطا انجام می‌شود.
- **یادداشت‌ها**: در `modules/notes.js` دو مدیریت جداگانه تعریف شده است. `NotesManager` برای یادداشت‌های عمومی و `DateNotesManager` برای یادداشت‌های متصل به تاریخ. هر دو از الگوی کارت HTML مشترک استفاده می‌کنند.
- **میانبرها**: `modules/quickAccess.js` قابلیت ساخت، ویرایش و حذف کارت‌های میانبر را با ذخیره در LocalStorage ارائه می‌کند. چک‌های اعتبارسنجی URL در سمت کلاینت انجام می‌شود.
- **نگه‌داری داده**: فایل `modules/storage.js` لایه‌ای ساده روی LocalStorage با fallback در حافظه ایجاد کرده است تا در محیط‌هایی که LocalStorage غیرفعال است هم برنامه کار کند.
- **واکنش‌گرا**: فایل `shared/styles.css` شامل گرید اصلی (سه ستونه)، نسخه‌ی دوسطونی و تکی برای عرض‌های کمتر است. فرم‌ها و کارت‌ها با گوشه‌های گرد و سایه‌ی نرم طراحی شده‌اند تا با وایرفریم تمرین منطبق باشند.

## آزمایش

1. فایل `web/index.html` را باز کنید و سناریوهای زیر را انجام دهید:
   - عبارت جستجو را وارد کرده و با Enter مطمئن شوید Google در زبانه‌ی جدید باز می‌شود.
   - چند میانبر جدید با ایموجی بسازید، سپس حذف و دوباره بارگذاری صفحه را تست کنید تا ماندگاری داده تأیید شود.
   - یادداشت عمومی ایجاد/ویرایش/حذف کنید.
   - در تقویم تاریخ‌های مختلف را انتخاب کرده، برای هرکدام یادداشت بسازید و نقطه‌ی نارنجی روزهای دارای یادداشت را ببینید؛ پاک‌کردن یادداشت باید نقطه را حذف کند.
   - دکمه‌ی «تقویم: شمسی» را بزنید و صحت محاسبه‌ی ماه‌ها، سال‌ها و لیست روزها را بررسی کنید؛ بازگشت به میلادی نیز بدون از دست رفتن داده انجام می‌شود.
2. همان تست‌ها را بعد از بارگذاری افزونه به‌صورت پنل مرورگر تکرار کنید تا مطمئن شوید در هر دو محیط رفتار یکسان است.

## توسعه و نگه‌داری

- برای اعمال تغییر در رابط، فقط فایل‌های موجود در `extension/shared` را ویرایش کنید؛ نسخه‌ی وب به‌صورت خودکار از همان فایل‌ها استفاده می‌کند.
- اگر آیکن‌های جدیدی نیاز داشتید، تصاویر PNG جدید را در `extension/icons` جای‌گذاری کرده و مراجع در `manifest.json` را به‌روزرسانی کنید.
- در صورت نیاز به همگام‌سازی داده‌ها بین دستگاه‌ها می‌توانید به‌سادگی به‌جای LocalStorage از `chrome.storage.sync` استفاده کنید؛ لایه‌ی `modules/storage.js` نقطه‌ی مناسبی برای تغییر است.
